# Room Setup and Invite — Comp Brief

Status: Card-mode/invite v3 approved by owner
Workflow: Impeccable comp-first; no production UI code before approval

## Purpose

Let a host make one setup decision at a time, then invite friends without requiring an account or app installation. The setup must feel calm and guided rather than like a configuration dashboard.

## Comparison comp

The portrait comparison shows two points in the room-creation journey:

1. **Card mode:** the first of three focused steps asks who handles the cards. Physical cards is selected for Release 1. Digital cards remains visible but clearly unavailable until its later release. A short note explains that the Table Controller can be reassigned before play.
2. **Invite:** after room creation, the host receives a prominent QR code and unambiguous four-letter locator. `Share invite` is the single dominant action; `Copy code` and `Open lobby` remain quiet alternatives. A valid QR, shared link or manually entered room code proceeds to name entry and the lobby without host approval.

Release 1 does not ask the host to choose both a format and a variant when only one combination is available. The three setup steps are card mode, stakes and review. The review explicitly confirms `Texas Hold’em · Cash game`; a separate choice step appears only after another format or variant is enabled.

The illustrative room code is `KJRM`; production room codes are generated by the server and exclude ambiguous letters. Code-only joins do not require host approval in the approved initial workflow.

## Visual rules

- Apple: a single question and dominant action per setup step; familiar portrait ergonomics and large targets.
- Porsche: exact header, progress, choice-row and button alignment.
- Bang & Olufsen: warm mineral surface and restrained material treatment without decorative cards.
- Linear: quiet secondary actions and clear hierarchy around the QR code and room locator.
- Use spacing and hairlines instead of stacked containers.
- A checkmark communicates the selected option once; unavailable options use text as well as reduced emphasis.
- Never expose the private host capability in the invitation UI or player share link.
- No dashboard grid, nested cards, oversized pills, gradient, glass, glow, casino decoration or invented branding.

## Release note

This comp reflects the approved Release 1 boundary: Physical Card Mode is available and Digital Card Mode is labelled for a later release. When Digital Card Mode ships, the disabled status is removed without changing the decision pattern.

Digital Card Mode is deferred, not cancelled. Its binding implementation handoff is recorded in [Future Release Handoff.md](../Poker%20Chips/Future%20Release%20Handoff.md).
